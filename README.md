A single-line roast of a fridge whose ice maker quit in 2019 and whose light only works when it feels appreciated.

## Run it

```sh
node main.ts
```

This writes the roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is unset).
